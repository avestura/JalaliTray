تاریخ شمسی، میلادی و قمری

با نگه‌داشتن ماوس روی آیکون، تاریخ کامل هر سه تقویم را در راهنما می‌بینید.

۰۳

با کلیک، پنجره‌ی تقویم کنار نوار وظیفه باز می‌شود و با کلیک بیرون از آن بسته می‌شود. ساعت زنده هم دارد.

۰۴

مناسبت‌ها و تعطیلات

مناسبت‌ها از API سایت time.ir خوانده و ذخیره می‌شوند. بدون کلید یا بدون اینترنت، داده‌ی آفلاین داخلی نمایش داده می‌شود.

۰۵

پرسش‌های پرتکرار

پاسخ سؤالتان را پیدا نکردید؟ در گیت‌هاب یک issue باز کنید.

گزینه‌ی NTP ساعت ویندوز را تغییر می‌دهد؟

خیر. وقتی در تنظیمات فعالش کنید، برنامه اختلاف ساعت را از ntp.time.ir می‌گیرد و فقط برای محاسبه‌ی تاریخ و ساعت خودش به کار می‌برد. نیازی به دسترسی مدیر نیست.

برای مناسبت‌ها به کلید API نیاز است؟

API سایت time.ir کلید می‌خواهد. اگر کلید خود را در تنظیمات وارد کنید، مناسبت‌ها از آن گرفته می‌شود. بدون کلید، تعطیلات رسمی و مناسبت‌های اصلی از داده‌ی آفلاین داخلی نمایش داده می‌شود. تعطیلات قمری در داده‌ی آفلاین تقریبی است و با گزینه‌ی تعدیل تاریخ قمری قابل اصلاح است.

برنامه چه اطلاعاتی ذخیره یا ارسال می‌کند؟

تنظیمات و حافظه‌ی نهان مناسبت‌ها فقط در پوشه‌ی %AppData%\JalaliTray روی همین رایانه می‌ماند. ارتباط شبکه فقط زمانی برقرار می‌شود که NTP یا کلید API را فعال کرده باشید.

چطور با ویندوز اجرا شود؟

در تنظیمات، گزینه‌ی «اجرا همراه ویندوز» را روشن کنید. برای باز کردن تنظیمات روی آیکون راست‌کلیک کنید.

آیکون در بخش مخفی نوار وظیفه است.

ویندوز آیکون‌های جدید را اول در منوی بالارونده‌ی نوار وظیفه می‌گذارد. آیکون را به نوار وظیفه بکشید تا همیشه دیده شود.
